# Change Log

All notable changes to the "lucy-language" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## 0.3.1

- Highlight the data of a send: `send(parent, removed, self)`.

## 0.3.0

- Highlight input declarations: `input name` and `input name(Type)`.
- Highlight the values in a spawn's block: `event.data`, `context.key`, `self` and `parent`.

## 0.2.0

- Highlight event declarations: `event name` and `event name(Type)`.
- Highlight action, guard, context and invoke names that have digits or underscores.

## 0.1.0

- Initial release
